
# Barangay 69

Barangay 69 is a web-based barangay management system designed to make resident registration and barangay service requests easier to manage.

## Live Website

https://barangayconnect-0j3m.onrender.com/

## GitHub Repository

https://github.com/johngorres666/BarangayConnect

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- Supabase
- Git and GitHub
- Render

## Main Features

- Online resident registration
- Admin review of resident applications
- Approve and reject resident registrations
- Online barangay service requests
- Service request management
- Admin dashboard with summary statistics
- Resident record management

## Installation and Setup

### Prerequisites

- Node.js
- npm
- PostgreSQL database (Supabase)

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/johngorres666/BarangayConnect.git
   ```

2. Navigate to the project folder:

   ```bash
   cd BarangayConnect
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the project root and configure the database connection variables required by `db.js`.

5. Start the application:

   ```bash
   npm start
   ```

6. Open your browser and visit:

   http://localhost:3000

## Project Deployment

The application is deployed using Render, with Supabase providing the PostgreSQL database.
